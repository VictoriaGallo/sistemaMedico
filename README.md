## 📌 Descripción del Proyecto

El **Sistema de Gestión Médica** es una aplicación web diseñada para optimizar los procesos administrativos, clínicos y financieros de un consultorio médico especializado en cirugía plástica.

Este sistema permite la gestión integral de pacientes, citas, historia clínica, cotizaciones, programación quirúrgica y facturación, centralizando toda la información en una plataforma segura y accesible.

---

## 🎯 Objetivo

Facilitar la administración del consultorio médico mediante la digitalización de procesos, mejorando la eficiencia operativa, la trazabilidad de la información y la experiencia de los usuarios.

---

## 🚀 Funcionalidades Principales

### 🔐 Gestión de Usuarios

* Creación, edición y eliminación de usuarios
* Asignación de roles (Administrador, Doctor, Secretaria, Programación)
* Control de permisos y accesos

### 👤 Gestión de Pacientes

* Registro de datos personales y médicos
* Actualización de información
* Consulta rápida de pacientes

### 📅 Agenda y Citas

* Programación de citas médicas
* Validación de disponibilidad
* Confirmación, cancelación y reprogramación

### ⏳ Sala de Espera

* Visualización en tiempo real del estado de pacientes
* Control de flujo de atención

### 📋 Historia Clínica

* Registro de consultas médicas
* Diagnósticos y tratamientos
* Adjuntos (exámenes, imágenes, documentos)

### 🏥 Plan Quirúrgico

* Creación y edición de planes quirúrgicos
* Registro de procedimientos y materiales
* Generación de cotización automática

### 💰 Cotizaciones

* Generación de presupuestos médicos
* Gestión de tarifas
* Impresión y exportación

### 🧾 Facturación

* Administración de cobros
* Control financiero del consultorio

### 📄 Documentos y Plantillas

* Generación de órdenes médicas
* Plantillas reutilizables
* Exportación a PDF/Excel

### 🔍 Búsqueda Avanzada

* Búsqueda por nombre o documento
* Acceso rápido a información del paciente

### 📊 Auditoría y Logs

* Registro de acciones del sistema
* Seguimiento de cambios importantes

---

## 👥 Tipos de Usuarios

### 👨‍💼 Administrador

## 📦 Instalación

```bash
# Clonar el repositorio
git clone https://github.com/VictoriaGallo/sistemaMedico.git

# Entrar al proyecto
cd sistema-gestion-medica

# Instalar dependencias (frontend)
npm install

# Ejecutar aplicación
npm start
```
